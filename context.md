# Quilted Languages — Project Context

> **For Claude instances**: read this first, then `README.md`. `design_doc.pdf`
> is the source of truth for design intent.

## What this is
Interactive site comparing loanword histories of **Romanian** and **Japanese**
(by Taizo Wiggins). Both languages grew up beside empires, and each era's
dominant power left a layer of borrowed words.

## Layout
- `app/` — source. React 19 + TanStack Start + Vite 7 + Tailwind 4, TypeScript.
- Repo root — the built static site GitHub Pages serves (`main`, `/ (root)`).
  Generated by `cd app && npm run pages` (`app/scripts/export-pages.mjs`); the
  generated files are listed in `.pages-files`. Never hand-edit them.

## Content (edit only these to change content)
- `app/src/data/words.ts` — every word (`w()` helper; type in `app/src/data/types.ts`).
- `app/src/data/eras.ts` — per era (prehistory, 500s, 1400s, 1600s, 1850s,
  1950s, 2000s) a Romania side and a Japan side: blogTitle, body paragraphs
  (Taizo's text, verbatim), leadWordId, exampleIds, sources.
- `app/src/data/resources.ts` — Resources page items (empty = "coming soon").
- `app/src/content/en.ts` — all interface and page text.

## Rules
- Never invent words, etymologies, dates or sources. Missing content is an
  empty field, which shows a designed "coming soon" state.
- Romanian ș ț only (U+0219, U+021B); the build fails on cedilla ş ţ.
- Every foreign word in the UI gets `lang="ro"` or `lang="ja"`.
- Plain `<a href>`, `<form action>` and head links need `withBase()` from
  `app/src/lib/base.ts` (the site lives under `/palimpsest-rom-jpn/`);
  `<Link>` adds it by itself.
- No forms, accounts, cookies, analytics or ads: the audience is under 18.
- Palette: void #02101f, ink #03254c, blue #1f4068, paper #e0e7ff,
  bar #c3cff2, mist #a9b8e3 (tokens in `app/src/styles.css`). Fonts: Source
  Serif 4, Source Sans 3, Noto Sans JP (subset by `npm run fonts:ja`).
- Signature components: the globe (`app/src/components/signature/globe`) and
  the quilt (`app/src/components/signature/quilt`).

## Checks
`cd app && npm run typecheck && npm run pages` — the export fails on a
cedilla, a duplicate word id/slug, a broken prerender or a missing 404 page.
